## How to Use

1. Open `index.html` in any modern browser.
2. All navigation links work between pages.
3. Replace placeholder text and image areas with real content and photos.
4. Forms are front-end only – connect them to a backend or form service later.

## Customisation

- Edit `assets/css/style.css` to change colours, fonts and layout.
- Primary colour: deep navy (#1a365d)
- Accent colour: gold (#c9a227)
